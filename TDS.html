Introduction

Insurers face a fascinating challenge every day in conducting business; they must sell a product for a certain price that carries an uncertain cost. In tackling this problem, insurers strive to build the best possible predictive risk and pricing models, to distinguish between the low and high-risk customers in the marketplace. The span of statistical models used for this task is wide and varied, from the enduring GLM to the intricate Feed Forward Neural Network (FFNN). Recently, some very promising new models have arrived on the scene, including the Combined Actua rial Neural Network (CANN), and the LocalGLMnet. Both of these models combine GLMs and neural networks to avail of the relative strengths of each architecture. This article will explain how the above four model architectures work, and will test how they perform on a dataset of real-world motor insurance policies. Buckle up!

(Note that the Actuarial Data Science Working Party would like to acknowledge the following authors for their original development and research on these architectures: Mario V. Wüthrich, Michael Merz and Jürg Schelldorfer for CANN; Ronald Richman and Mario V. Wüthrich for LocalGLMnet.)

GLM

A GLM is a model of the form:

\[ \tag{1} \hat{y} = g(X \beta + \beta_0) \]

where \(X \in \mathbb{R}^{n \times p}\) is the matrix of input features, \(\beta \in \mathbb{R}^p\) is the vector of coefficients, and \(\beta_0 \in \mathbb{R}\) is the intercept.

The predicted values \(\hat{y}\) are then obtained by applying a link function \(g\) to the linear predictor:

\[ \tag{1} \hat{y} = g(\eta) \]

In the context of a Poisson regression, the link function \(g\) is the exponential function, leading to:

\[ \tag{1} \hat{y} = \exp(\eta) \]

We want to find such \(\beta\) vector that minimizes a loss function \(\mathcal{L}(y,hat{y})\) which decreases as the predicted \(\hat(y)\) gets closer to actual \(\y\). In our example we’re modeling claim frequency so we choose poisson loss and a log link activation: \(\g(x) = exp(x)\) and the loss:

\[ \mathcal{L}(\hat{y}, y) = \sum_{i=1}^{n} (\hat{y}_i - y_i \log(\hat{y}_i)) \]

Although in practice this optimization problem might be solved iteratively, there exists a closed form solution to this problem, which - importantly - is not the case in neural nets. There are many packages that allow us to train a glm with a selection of loss functions and optimizers. To fit a basic poisson GLM In R we can use the preinstalled stats package:

Here, \(\hat{y}_i\) represents the predicted values and \(y_i\) represents the observed values.

Neural Network

Let’s come back to equation (1) and forget about the statistical context for a moment. Now, the g() transformation of the linear predictor (activation) is a chosen sigmoidal function and the optimal betas are obtained iteratively starting from a set of random values. Evaluating this randomly initialized function - neuron - would yield a poor result, far from our target, but the idea here is that we can ensemble an arbitrary number of them to produce a prediction in tandem and iteratively tweak the all betas to minimize the loss. Multiple neurons together form a layer and their result vector can be passed to another layer or the single (output) neuron.

In contrast to a GLM, this architecture is very flexible and we can put together n_i of layers with arbitrary number of neurons and activations aiming for a model that is capable of representing non-linearities in our data accurately.

Let us define this feed-forward neural network architecture. Choose the number of layers \(k \ge 1\) and \(q_{k-1}, q_k \in \mathbb{N}\) neurons in hidden layers. A network layer is a mapping

\[ \tag{1} f_k(x) = W_k x + b_k \]

with \(q_k\) hidden neurons in the \(k\)-th hidden layer given by

\[ \tag{*} h_k = \sigma(f_k(x)) \]

with weights

\[ \tag{*} W_k \in \mathbb{R}^{q_k \times q_{k-1}}, \quad b_k \in \mathbb{R}^{q_k} \]

and activation function

\[ \tag{*} \sigma: \mathbb{R} \rightarrow \mathbb{R} \]

A general network architecture with \(K\) hidden layers for our Poisson regression problem is then obtained by adding an output layer as follows:

\[ \tag{*} \hat{y} = g(W_{K+1} h_K + b_{K+1}) \]

LocalGLMnet

In the CANN model, we combined a NN with a GLM by having the models predict in series, and together calculate the prediction for frequency. The LocalGLMnet combines the neural network and GLM in a very different way. We know that the GLM consists of a linear combination of parameters (βs), connected to the response variable through a link function. One set of parameters is used to predict for all records in the dataset. However, what if we could have a different set of parameters for each individual record in the dataset? This way, the different effect of variables on different customers can be captured in a very granular way - there is a custom set of βs for each customer in the dataset. This is what the LocalGLMnet achieves. The innovation of the LocalGLMnet is that a FFNN models the beta parameters for each customer. Then, the prediction for that customer is calculated with those βs in a GLM formula – something we are very familiar with. By retaining the GLM structure in the calculation of predictions in this way, we gain the advantages of a GLM’s explainability. The FFNN’s ability to model complex relationships in the data is still leveraged through the customer-specific calculation of the β parameters.

The purpose of LocalGLMnets is to replace the (constant) regression parameters β=(β0,….q0)T by covariate dependent regression attentions x=1xqxT , which are modeled by FFN networks. Now we can consider a FFN network architecture of depth d Є N with input and output dimensions being equal to q0=qd=q to model the regression attentions (β parameters):

\[\begin{align*} a & = b \\ X &\sim {\sf Norm}(10, 3) \\ 5 & \le 10 \end{align*}\]

The LocalGLMnet is defined by the additive decomposition:

\[\begin{align*} a & = b \\ X &\sim {\sf Norm}(10, 3) \\ 5 & \le 10 \end{align*}\]

This simply means that for each customer, we calculate their prediction using the familiar GLM formula with link function. The β parameters in the GLM formula are different for each customer, as they depend on each customer’s profile, and are calculated by a FFNN. This naturally leads us to study the distribution of β parameter values across the levels of each variable in the model, for all policies in the dataset. From this, we can utilise the LocalGLMnet’s advantages in terms of interpretability, while also producing a model with greater ability to model complex interactions. When interpreting the β parameter values in this way, there are some cases in particular to watch out for: The Beta parameters can be used to determine the variables’ importance: · If βj(x)=0 we can try to drop the term xj, because it isn’t contributing to the prediction · If βj(x)=βj we obtain a GLM term in xj, so the is not feature dependent · If βj(x)=βj(xj) there are no interactions of term xj with xj’ And you can also compute an importance measure as follows:

\[\begin{align*} a & = b \\ X &\sim {\sf Norm}(10, 3) \\ 5 & \le 10 \end{align*}\]

Also, the interaction effect in a variable can be quantified by calculating the gradient of the parameter’s values along the dimensions of other potentially interacting variables: βj(x).

Model fitting

To compare models’ performance we analyse the results of a 5 fold cross validation exercise. The code we presented earlier for each of the architectures is a bare minimum that yields a predictive model. In order to reference the hyperparameters in a common way we prepared a series of wrapper functions. Apart from aiding in handling the training, they are the same as the ones we covered above.

We preprocess the data before feeding it to the models. This process is handled by the peproc() function. We choose to normalize the numerical variables and one-hot encode the categoricals. In order to avoid information leakage this function uses only the information from the training dataset. Note - it is possible to randomly select such a train-test split where the test set contains values of categorical variables previously unseen in training.

On a high level this procedure is simple but if you would like to train the models on your machine pulling our github repository is advised as we didn’t show here all of the preprocessing/helper functions used below.

CV = 5 # K Folds

# fold ID for each observation
CV_vec = sample(1:CV,replace = T,size = nrow(fre_mtpl2_freq))

# objects to store results
models = list()
results = list()
losses = data.frame(CV = paste0("CV_",1:CV),
                    glm = NA,
                    ff_nn = NA,
                    localGLMnet = NA,
                    CANN = NA,
                    XGB = NA)

# Cross Validation loop
for (i in 1:CV){
  
  train_rows = which(CV_vec != i)
  
  models[[paste0("CV_",i)]] = list()
  
  # object for storing per model/observation results
  results[[paste0("CV_",i)]] = data.frame(ID = fre_mtpl2_freq$IDpol[-train_rows],
                                          actual = fre_mtpl2_freq$ClaimNb[-train_rows],
                                          glm = NA,
                                          ff_nn = NA,
                                          localGLMnet = NA,
                                          CANN = NA) %>% 
    mutate(homog = mean(fre_mtpl2_freq$ClaimNb[train_rows]))
  
  # data preprocessing
  encoder = preproc(dt_frame = fre_mtpl2_freq[train_rows,],
                    y = "ClaimNb",
                    num = "norm",
                    cat = "ohe",
                    bypass = NULL,
                    exclude = c("IDpol","Exposure"),
                    verbose = T)
  
  # train - test split
  train = encoder(fre_mtpl2_freq[train_rows,])
  test = encoder(fre_mtpl2_freq[-train_rows,])
  
  # homogenous model ------------------------------------------------- 
  
  losses$homog[i] =poisson_deviance(y_true = results[[paste0("CV_",i)]]$actual,
                                    y_pred = results[[paste0("CV_",i)]]$homog)
  
  # GLM ------------------------------------------------- 
  
  models[[paste0("CV_",i)]]$glm_model = glm(formula = ClaimNb~.,
                                            family = poisson,
                                            data = fre_mtpl2_freq[train_rows,-c(1,3)])
  
  results[[paste0("CV_",i)]]$glm = as.vector(predict(models[[paste0("CV_",i)]]$glm_model,
                                                     fre_mtpl2_freq[-train_rows,-c(1,3)],type="response"))
  
  losses$glm[i] = poisson_deviance(y_true = results[[paste0("CV_",i)]]$actual,
                                   y_pred = results[[paste0("CV_",i)]]$glm)
  
  # ff_nn - Feed Forward Neural Network ------------------------------------------------
  
  models[[paste0("CV_",i)]]$ff_nn_model = train_ff_nn(dt = train[,-1],
                                                      y = train[,1],
                                                      vdt = list(x_val = test[,-1],
                                                                 y_val = test[,1]),
                                                      n_dropout = c(F,F,F),
                                                      n_layers = 3,
                                                      n_units = c(20,15,15),
                                                      n_activ = c("sigmoid","sigmoid","sigmoid"),
                                                      lr = 0.005,
                                                      bs = 2^12,
                                                      ep = 1000)
  
  results[[paste0("CV_",i)]]$ff_nn = predict(models[[paste0("CV_",i)]]$ff_nn_model,test[,-1])[,1]
  
  losses$ff_nn[i] = poisson_deviance(y_true = results[[paste0("CV_",i)]]$actual,
                                     y_pred = results[[paste0("CV_",i)]]$ff_nn)
  
  # LocalGLMnet -------------------------------------------
  
  models[[paste0("CV_",i)]]$localGLMnet_model = train_LocalGLMnet(dt = train[,-1],
                                                                  y = train[,1],
                                                                  vdt = list(x_val = test[,-1],
                                                                             y_val = test[,1]),
                                                                  n_dropout = c(F,F,F),
                                                                  n_layers = 3,
                                                                  n_units = c(20,15,15),
                                                                  n_activ = c("tanh","tanh","tanh"),
                                                                  lr = 0.005,
                                                                  bs = 2^12,
                                                                  ep = 1000)
  
  results[[paste0("CV_",i)]]$localGLMnet = predict(models[[paste0("CV_",i)]]$localGLMnet_model,test[,-1])[,1]
  
  losses$localGLMnet[i] = poisson_deviance(y_true = results[[paste0("CV_",i)]]$actual,
                                           y_pred = results[[paste0("CV_",i)]]$localGLMnet)
  
  # CANN  - Combined Actuarial Neural Network ------------------------------------------
  
  #weights - used as initialization
  learn_GLM = fitted(models[[paste0("CV_",i)]]$glm_model)
  test_GLM = results[[paste0("CV_",i)]]$glm
  
  w_learn = as.matrix(log(learn_GLM))
  w_test = as.matrix(log(test_GLM))
  
  models[[paste0("CV_",i)]]$CANN_model = train_CANN(dt = train[,-1],
                                                    y = train[,1],
                                                    vdt = list(x_val =list( test[,-1], w_test),
                                                               y_val = test[,1]),
                                                    w=w_learn,                                                    
                                                    n_layers = 3,
                                                    n_units = c(20,15,15),
                                                    n_activ = c("tanh","tanh","tanh"),
                                                    lr = 0.005,
                                                    bs = 2^12,
                                                    ep = 1000)
  
  results[[paste0("CV_",i)]]$CANN = predict(models[[paste0("CV_",i)]]$CANN_model,list(as.matrix(test[,-1]),w_test))[,1]
  
  losses$CANN[i] = poisson_deviance(y_true = results[[paste0("CV_",i)]]$actual,
                                    y_pred = results[[paste0("CV_",i)]]$CANN)
  
}
